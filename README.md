# Spurthi Mudunuri | A Museum of Trying

My personal resume website, built with HTML and CSS for the Web Development mid-term project.

**Live website:** https://spurthi-blip.github.io/spurthi-resume-assignment/
**GitHub repository:** https://github.com/spurthi-blip/spurthi-resume-assignment

## About the project

The site is built around one idea, a "museum of trying". My roles are shown as exhibits and my competition certificates as "attempts, on record". Sections: home, what i do, about, education, exhibits, attempts, tools and contact.

## Project structure

```
index.html      page structure and content
style.css       all the styling
images/
  profile.jpg       my photo
  certificate1.jpeg Crown Jewel 2026 certificate
  certificate2.jpeg CaseBlitz 2026 certificate
```

## Design

- Fonts (Google Fonts): Bricolage Grotesque for headings, DM Sans for body text, Caveat for the photo badge
- Colours: powder blues (#EAF3FA, #BFD9EE, #D5E6F4), navy (#14274A) and a tangerine accent (#F28C28)
- Sticky flexbox navigation bar, CSS grid layouts, hover effects, a certificate lightbox, and media queries for phones

## Built with

HTML, CSS and a little JavaScript for the certificate pop-up. Hosted on GitHub Pages.
